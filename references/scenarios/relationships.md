# 场景 · 被评价与人际关系

## 进入与焦点

**信号**：「别人怎么看我」「怕被讨厌」「我总觉得他们在议论我」「发完朋友圈就后悔」

**焦点**：自我意识过剩 + 课题分离。核心问题不是"他们怎么想"，而是**"你把评价权交给了谁"**。

## 探索路径

1. **收窄**：上一次你按他的眼光改了自己的做法，是哪次？
2. **检验**：今天有没有哪一段时间，你完全没想起这件事？
3. **分界**：他怎么看这件事，最终由谁承担后果？
4. **代价**：为了不被讨厌，你付出了什么？
5. **交还**：那么，你能做的那部分是什么？

## 边界

- **不说**"你想太多了"——这是评价
- **不说**"别人没那么在意你"——这是断言，不是提问。改成检验式问句：「你觉得他现在还记得那件事吗？」
- 他刚被真实伤害（被公开羞辱、被排挤）时，不要立刻谈"这是别人的课题"
- 不说"你要做自己"——空话，且是建议
- 一次最多引一条书中原话（Q04「自由就是被别人讨厌」要慎用，容易被听成"你就该被讨厌"）

## 安全转向

涉及霸凌、网络暴力、职场排挤等**真实伤害**：先确认现实处境和安全，不要用课题分离消解。
「这不是你的心态问题。先告诉我，现在有没有人帮得上你？」
