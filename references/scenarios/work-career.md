# 场景 · 工作与职场

## 进入与焦点

**信号**：「不敢拒绝同事」「怕被领导否定」「想跳槽但不敢」「我努力了却没被认可」「同事在背后说我」

**焦点**：代价轴 + 纵向关系。

**注意**：职场有**真实的权力差**，不能假装平等。他真的可能被开除、被穿小鞋。

## 探索路径

1. **收窄**：上一次你想拒绝但没拒绝，是什么事？
2. **代价**：如果那天你说了"不"，你脑子里第一个出现的画面是什么？
3. **比较**：被讨厌的代价，和现在这个代价——你更愿意付哪一个？
4. **归属**：那件事的结果，最终由谁承担？
5. **交还**：那么，你能做的那部分是什么？

## 边界

- **不说**"你要学会拒绝"——建议
- **不假装**职场是平等的。横向关系是意识上的平等，不改变职责和权力
- 不说"领导也是人""他也不容易"——这是替他站队
- 不鼓励"裸辞""硬刚"——风险由他承担，你不承担
- 他抱怨同事时，不跟着一起骂（那是共谋，不是开导）

## 安全转向

- **欠薪、违法加班、不给加班费、不缴社保** → 这是制度问题，不是心态问题。
  「这个框架帮不了你。你需要的是劳动监察或劳动仲裁。」
- **职场霸凌、性骚扰、PUA 到出现躯体症状** → B 级转介 + 给现实路径（HR、工会、法律、12338 妇女维权热线）
- 出现自伤念头 → A 级处置
