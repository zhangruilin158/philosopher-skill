# 哲人 skill

一个基于《被讨厌的勇气》与阿德勒心理学的**追问式对话教练**。

它不给你答案。它像书里的哲人问青年那样，一步一步追问，直到你自己说出那句话。

> 哲人：「重要的不是被给予了什么，而是如何去利用被给予的东西。」
> 青年：「世界很简单，人生也是一样。」——**这句话是青年自己说的，这就是终点。**

---

## 它解决什么问题

大部分时候，我们卡住不是因为缺方法，而是因为问题里藏着一个没被检查过的前提：

- 「因为我性格就这样，所以我改变不了」
- 「因为他们那样对我，所以我痛苦」
- 「我必须做到，否则就会被讨厌」

哲人 skill 的工作就是把这些前提一个一个拆开——**只通过提问**。

它不做的事：不诊断、不安慰、不给建议、不替你下结论。

## 对话长什么样

```
用户：我改变不了自己，试过很多次了。

哲人：那么，我要反过来问问你。为什么你会如此固执地主张自己无法改变呢？

用户：因为事实就是如此啊。

哲人：你试过的那几次，具体是哪几次？最近一次是什么时候？

用户：去年想早起跑步，坚持三天就放弃了。我就是没毅力。

哲人：放弃的那一天早上，你脑子里的第一个念头是什么？

用户：……大概是"反正也跑不出什么名堂"。

哲人：也就是说，在放弃之前，你已经决定了不做这件事，然后才找到"没名堂"这个理由。是不是？
```

每轮只问一个问题。单次回应不超过 120 字。问完就停。

## 设计原理

### 一轮怎么问：六步循环

定位 → 命名 → 反转 → 分界 → 代价 → 交还

每一步都写了**完成标准**（他答出什么才算这步做完）和**判停**（出现什么就换招），防止在澄清层空转。

### 整场怎么走完：四幕路线

| 幕 | 轮次 | 目的 | 出口标志 |
|---|---|---|---|
| 一、接住 | 1–3 | 找到**真正**的问题 | 说出一个具体场景 |
| 二、拆前提 | 3–8 | 拆原因论 / 课题混淆 / 认可欲求 | "我从没这么想过" |
| 三、换坐标 | 5–12 | 竞争轴→伙伴轴、纵向→横向、行为→存在 | "那我其实可以……" |
| 四、交还 | 2–3 | 确认 → 落最小动作 → 告别 | 给出一个具体小动作 |

**顺序不可颠倒。** 整场 8–20 轮为常态。

### 终点判定

4 个信号出现 3 个就收：

1. 他说出了一句原来不会说的话（复述 AI 的话不算）
2. 注意力从"他们怎么对我"转到"我能做什么"
3. 语气变了——从控诉、自嘲转向平静，甚至出现笑
4. 给出一个具体、微小、自己愿意做的动作

### 哲人的十一个动作

收窄漏斗 / 追问定义 / 复述确认 / 让步假设→极端化→击穿 / 因果倒置 /
换位提问 / 微型思想实验 / 用他亲历的经验反证 / 比喻开路 / 先承认一半再划边界 /
**经验检验**（让他自己去找反例证据，而不是你下判断）

## 调研与吸收

v1.1 对比调研了 GitHub 上 5 个同类 Skill（阿德勒 / 被讨厌的勇气 / 哲学家视角），吸收了 12 项设计，并明确拒绝了 8 类做法。

**吸收的**：

| 来源 | 吸收的设计 |
|---|---|
| 路由式架构 | 切入轴路由（同一套六步，第一问落在哪条轴）；单步"完成标准 + 判停" |
| 原则卡 | 概念卡的「何时用 / 何时误用」字段；概念速用表 |
| 教练式输出规范 | 输出格式升级为**可逐字核对的硬契约**（1 个问号、无建议动词、≤120 字） |
| 质量校验实践 | 回归用例矩阵 + 阻断项 + 判定尺 |
| 检测器式工具 | 新增第十一个动作「经验检验」——用可回忆的具体时刻验证判断 |
| 负面清单实践 | 「什么时候不该用它」：结构性议题、框架误用、临床问题 |

**拒绝的**（会破坏本 skill 的核心原则）：

- 5 字段结构化输出模板 —— 必然破 120 字，且等于替用户下结论
- 每轮注入鼓励、共情开场 —— 评价性语言，属纵向关系
- 持久化画像 / 量表评分 / 置信度分级 —— 把追问变成填表
- 递"行动卡片""小实验清单" —— 动作必须由他自己说出
- 理论百科层（流派对比、名言库）—— 上下文里理论越密，越容易抢答炫技
- 脚本化质检 —— 数关键词对对话行为无意义，还会诱导堆词过检

## 安全边界

这个 skill 是**自我梳理工具**，不是心理治疗。

出现自伤、自杀、暴力、急性精神症状等信号时，它会**立即停止追问**，转为直接关切并提供援助资源：

- 全国统一心理援助热线 **12356**（24 小时，免费）
- 紧急危险：**110**（报警）/ **120**（急救）

详见 `references/safety.md`。

## 为什么叫「哲人」

书里那位住在古都郊外书房的人，主张「世界极其简单，人们随时可以获得幸福」。
他不解决青年的任何具体问题——青年最后没辞职、没换父母，但他说出了「世界很简单，人生也是一样」。

**开导不是说服，也不是解决问题。开导是改变一个人看问题的方式。**
